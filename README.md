# 🧠 Quiz App

A simple and interactive Quiz Application built using HTML, CSS, and JavaScript. The application allows users to answer multiple-choice questions, check their answers, and track their score.

## 🚀 Live Demo

🔗 [View Live Application](https://asr1706.github.io/Quiz-App/)


---

## 📌 Features

- Interactive multiple-choice quiz
- Multiple questions
- Answer selection
- Score calculation
- Displays correct and incorrect answers
- User-friendly interface
- Simple and responsive design

---

## 🛠️ Technologies Used

- **HTML** – Structure of the application
- **CSS** – Styling and layout
- **JavaScript** – Quiz logic and interactivity
